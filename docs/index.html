One color, five answers. This band is a neutral gray on purpose. Judging a color against a colored surround shifts what you see, which is the first thing the app has to teach and the first thing a page about color should respect.

Start from your question

Six workspaces. You do not have to learn what they are called, because each one answers a question you already have.

  • Check
    Can people actually read this?

    Contrast against the five WCAG 2.2 thresholds, color-space limits, how far apart two colors really are, and whether meaning survives without color.

  • Convert
    What is this color in another notation?

    Enter a color once and read it back in any supported space, with every stage of the conversion open for inspection.

  • Build
    I need a palette that holds up.

    Design named roles rather than loose swatches, inspect the relationships the palette actually uses, then export the same roles to code.

  • Learn
    Why do these numbers behave this way?

    Four lessons on light, vision, measurement, and reproduction, each in three short parts, using the color you are already working on.

  • Explore
    What happens if I change this?

    Predict a result, change one thing, then compare what you saw with what the calculation says.

  • Reference
    What does this term mean?

    Definitions, equations, and standards, each with its source and the boundary of what it can tell you.

How it is built

Accessible by construction

Five color-vision palettes, each audited to WCAG 2.2 AA against the deficiency it is named for. Full VoiceOver headings, adjustable text scale, and support for Increased Contrast and Reduce Transparency.

Sourced, with stated limits

Every calculation names the standard behind it and says what it cannot tell you. CIEDE2000 matches all thirty four pairs of the Sharma, Wu and Dalal verification set.

Nothing leaves without your say

No account and no telemetry. Nothing is sent anywhere unless you turn on palette suggestions, which are off by default and talk only to an Ollama server you name, on this Mac or one you choose. Plaintext is refused to anything outside your own network.

Made to be read

Set in Atkinson Hyperlegible, the typeface designed by the Braille Institute to keep similar letterforms distinguishable at low acuity.

Get it

Download the disk image, open it, and drag the app to your Applications folder.

Download from GitHub Releases

macOS 14 Sonoma or later, Apple silicon. The build is signed locally rather than notarized, so the first launch needs Control-click, then Open. Source code is on GitHub.

Where this came from

Much of this began as teaching material for the color portion of a data visualization course I taught as an assistant professor at West Virginia University. It accumulated over several semesters as explanations, worked examples, and demonstrations that answered the questions students actually asked.

Collecting it into one app was a way to keep it in a form I could still use. If any of it is useful to you, for teaching, for design work, or out of plain curiosity about how color numbers behave, please take it.
