# Build 025: A sharper identity and dependable finishing details

Build 025 replaces the app icon with a flat, deliberate mark that belongs to the same visual family as the icons inside On Color Theory. Three overlapping color fields represent comparison and combination, while the centered target represents measurement. The editable SVG is the master for the Home artwork and every macOS icon size.

Help now gives every route the same presentation. Actions sit in a clearly labeled panel, use equal adaptive columns, and align their symbols and text to the leading edge. A divider and larger gap separate the saved-work reassurance from the installed version in the topic rail.

Cut, Copy, Paste, Paste and Match Style, Delete, and Select All now use the standard macOS responder chain in the main app, Inspector, Color Tray, Model Assist, Help, definition, and Settings windows. Reading text remains selectable, while native text fields and editors retain the platform editing behavior people expect.

The Reading preview in On Color Theory Settings now begins with “Color is more than what we see.” The font comparison characters remain directly below it.

The calculation and security checks from Build 024 remain in place. Build 025 adds direct coverage for the editing-command selectors and renders every Help topic as part of a 173-state interface matrix.
