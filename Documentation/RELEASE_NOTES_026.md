# Build 026: A restrained icon refinement and a complete reset path

Build 026 restores the luminous app icon introduced in Build 024 and changes only its center. A compact four-direction measurement cue now connects the app identity to the designed symbols used throughout On Color Theory. The rounded navy field, overlapping color spaces, coordinate ring, grid, palette, and overall composition remain intact.

The Home headline now reads "See color more clearly" without ending punctuation.

New installations now open in Dark appearance. People can still choose Follow Mac or Light in On Color Theory Settings, and their explicit choice remains saved.

Help adds a final Reset On Color Theory topic. Reset always clears workspace progress, the Color Tray, reading and appearance settings, saved window positions, and Model Assist preferences. Ollama and its models remain installed unless the person explicitly selects either local-cleanup choice and confirms the destructive action.

Local cleanup moves the standard local model folder and Ollama.app to the Trash, where they remain recoverable until the Trash is emptied. It never sends a deletion request to an external Ollama server. Selecting both cleanup choices returns On Color Theory to its full first-run state and reopens the Start here walkthrough. Every other reset keeps the walkthrough completed.
