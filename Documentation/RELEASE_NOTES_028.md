# Build 028: A true first-run walkthrough

Build 028 replaces the first-run Help launch with a dedicated seven-step walkthrough window. Each slide introduces one part of the app using a clear title, a short summary, and three focused points. Visible progress, Previous, Next, Skip walkthrough, and Start using On Color Theory controls keep the sequence predictable and accessible.

The walkthrough appears when On Color Theory is first opened and does not appear again after it is completed, skipped, or closed. Start here in Help includes an Open walkthrough action, so the complete sequence remains available whenever someone wants a refresher. A full reset that removes both local Ollama and its downloaded models returns the app to its true first-run state and opens this walkthrough again.

The app icon has also been rebalanced between the brighter Build 026 treatment and the darker Build 027 treatment. Its midtones and color relationships are clearer in Dark mode without returning to the earlier neon intensity.

Version: 0.28.0 (28)
